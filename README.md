# 📸 施工前・施工後 文字入れくん (`before-after-labeler`)

リフォーム・清掃・工事などの「施工前」「施工後」の写真に、**毎回同じフォント・見切れない安全な位置で「白文字＋黒縁取り」のラベルを自動合成**し、SNSやGoogleビジネスプロフィール向けに最適化して保存できるWebツールです。

---

## ✨ 主な機能

1. **3ステップの迷わない操作フロー**
   - **ステップ1**: 「施工前」の写真をアップロード（複数枚まとめアップ対応）
   - **ステップ2**: 「施工後」の写真をアップロード
   - **ステップ3**: 個別保存・ZIP一括保存・ビフォーアフター2枚合体（比較画像）保存

2. **投稿先に合わせた自動トリミング＆安全余白プリセット**
   - **📸 インスタ投稿（縦長 4:5）**: スマホ画面で大きく見やすく、一覧でも文字が見切れない右下5%余白
   - **🟦 インスタ投稿（正方形 1:1）**: 王道の正方形フォーマット
   - **📱 ストーリーズ（9:16）**: 下部のUIボタンに被らない安全配置
   - **🏢 Googleビジネス（4:3）**: 店舗の施工事例掲載に最適な比率と内側余白

3. **文字ラベルのカスタマイズ**
   - 「施工前 / 施工後」「Before / After」などの定型文切り替えや自由テキスト入力に対応。
   - 視認性の高い極太ゴシック体（Noto Sans JP）＋黒縁取りで、どんな背景色の写真でもくっきり読めます。

4. **iPhoneのHEIC写真＆ZIP一括ダウンロード対応**
   - `.heic` 写真の自動変換に対応し、複数枚処理した画像もワンクリックでZIP保存できます。

## 🚀 使い方・デプロイ方法

- **ローカル起動**: `index.html` をブラウザで直接開くだけですぐに使えます。
- **Cloud Run デプロイ**:
  ```bash
  ./deploy_cloud_run.sh
  ```
